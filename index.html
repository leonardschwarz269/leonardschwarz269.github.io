Проекты

Hermes Agent — личный AI-ассистент 24/7

Персональный AI-ассистент на собственном VPS, доступный из Telegram в любой момент. Ядро — open-source агентная платформа Hermes Agent, поверх которой написан собственный Telegram-роутер на Python: 30 модулей, тесты, автозапуск через systemd.

Ассистент закрывает реальные личные и рабочие задачи: ведёт несколько профилей под разные роли (работа, финансы, учёба, автобизнес — у каждого своя «личность» и база знаний), понимает голосовые сообщения, принимает документы и фото как контекст, выполняет автономные задачи по расписанию — от мониторинга сервера до регулярных отчётов, — работает с git и управляет собственным сервером.

Кейс: доступ без хаоса. Ботом пользуются несколько человек → построена система ролей (суперадмин/админ/пользователь) с одобрением новичков прямо из чата.
Кейс: файлы из AI в руки. Агент создаёт отчёты и документы на сервере → маркер FILE: доставляет их в Telegram документами автоматически.
Кейс: живучесть 24/7. Health-мониторинг, автоперезапуск и безопасный /restart из чата — ассистент восстанавливается сам, без доступа к серверу.

AutoRadar — AI-помощник в автобизнесе

Не просто парсер, а личный помощник профессионала: собирает объявления с площадок Китая, Кореи, США и Грузии, из Telegram-каналов и с любых сайтов — цены, характеристики, комплектации, фотографии → единый формат, фильтры по маркам и моделям, выгрузка. А по любой машине отвечает на вопросы как эксперт.

Кейс: любой источник — 1 формат. У каждой площадки и канала своя структура данных → нормализация приводит всё к единой схеме. Источники подключаются модульно: новую площадку или канал можно добавить без переделки системы.
Кейс: от объявления к экономике сделки. По собранным данным просчитывается стоимость машины под клиента — с учётом доставки, растаможки и подготовки. Вместо ручного просчёта каждого варианта — расчёт по готовым данным.
Кейс: фото без ручного скачивания. Парсер сам выгружает фотографии автомобилей из объявлений — готовый материал для карточек, публикаций и показа клиенту.
Кейс: друг-профессионал на связи. Любой вопрос по машине — слабые места модели, на что смотреть при осмотре, сравнение вариантов — и ответ от самых современных и быстрых LLM прямо в боте. Не только собирает объявления, но и помогает принимать решения.

Auto.ru Feed Pipeline — LLM-конвейер

LLM-цепочки превращают сырые данные парсера в готовые XML-фиды для автозагрузки Auto.ru и клиентский контент: описания, карточки, идеи для коротких видео и рекламных креативов.

Кейс: ноль ручного труда. Раньше карточка объявления писалась руками → теперь конвейер сам генерирует описание, характеристики и фид.
